Unified Robot Description Format，统一机器人描述格式

本质上是一个 XML 文件，用来描述一个机器人长什么样、有哪些连杆、关节怎么连接、每个零件的位置姿态、质量惯量、碰撞模型、可视化模型等。

在ROS中，URDF常用于：

  • 在 RViz 中显示机器人模型

  • 给 TF 系统提供机器人各个 link 的坐标关系

  • 给 Gazebo 做仿真模型基础

  • 给 MoveIt 做运动规划模型

  • 让 robot_state_publisher 根据 joint_states 发布机器人 TF

joint 类型 含义 例子
fixed 固定连接，不能动 相机固定在机身上
revolute 有限角度旋转关节 机械臂关节、机器狗腿关节
continuous 无限旋转关节 轮子
prismatic 直线滑动关节 电动滑轨
floating 六自由度浮动 移动基座，较少直接用
planar 平面运动 特殊二维运动模型
