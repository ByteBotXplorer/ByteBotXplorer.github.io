匿名函数

Created2026-03-14|Updated2026-03-14|编程C++
|Word Count:1.2k|Reading Time:4mins|Post Views:

What

C++中的匿名函数，也称为Lambda表达式，一种可以定义在表达式上下文中的函数对象。没有明确的名称，是由一个特殊的语法表示。通常用于简化代码，尤其在需要传递函数作为参数或创建临时函数对象时。

语法

组件 作用
捕获列表 [] 捕获当前作用域的变量（值 / 引用 / 隐式捕获），C++ 独有（Python 无此概念）
参数列表 () 同普通函数参数，可省略（无参数时）
返回值类型 -> 可省略，编译器会自动推导（C++11 起）
函数体 {} 支持任意复杂逻辑（循环、条件、多条语句）

捕获列表

捕获方式 含义 示例
[] 不捕获任何变量 [](){ return 1; }
[=] 隐式值捕获所有外部变量（只读） [=](){ return x + y; }
[&] 隐式引用捕获所有外部变量（可修改） [&](){ x++; y++; }
[x] 显式值捕获变量 x [x](){ return x * 2; }
[&y] 显式引用捕获变量 y [&y](){ y = 10; }
[this] 捕获类的 this 指针（类成员函数中使用） [this](){ this->func(); }

本质

  • 函数对象

    本质是一个函数对象，封装了函数的调用操作。编译器将Lambda表达式转换为一个类，这个类重载了operator()，使得该类对象可以像函数一样被调用。

  • 捕获列表

    Lambda表达式可以捕获其所在的上下文中的变量，这些变量被称为捕获列表。捕获列表决定Lambda表达式内部如何访问外部变量。

  • 函数体

    Lambda表达式有一个函数体，包含了函数的具体实现。

实现原理

  1. 编译器生成类

    编译器为每个Lambda表达式生成一个唯一的、匿名的类。

  2. 重载operator()

    生成的类会重载operator()，使得该类对象可以像函数一样被调用。

  3. 成员变量

    如果Lambda表达式捕获了外部变量，编译器会在生成的类中添加相应的成员变量来存储这些变量的副本或引用。

  4. 构造函数

    生成的类的构造函数会初始化这些成员变量。

  5. 函数体

    生成的类的operator()函数的实现就是Lambda表达式的函数体。

C++匿名函数就是通过编译器的语法糖，将函数对象的概念简化，使得代码更简洁。实现原理是编译器在编译时生成一个匿名的类，这个类包含了Lambda表达式的所有信息。
