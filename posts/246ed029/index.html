ROS 插件

Created2026-05-24|Updated2026-07-10|ROS
|Word Count:215|Reading Time:1mins|Post Views:

将动态链接库.so注册成插件的链条：

  1. C++ 代码中声明：在 realsense_node_factory.cpp 底部使用宏 PLUGINLIB_EXPORT_CLASS(realsense2_camera::RealSenseNodeFactory, nodelet::Nodelet)，在 .so 内部打下标记。

  2. XML 文件中索引：nodelet_plugins.xml 将标记暴露给 ROS 系统。

  3. package.xml 中导出：在 package.xml 中必须有 <export><nodelet plugin="${prefix}/nodelet_plugins.xml" /></export>，将 XML 文件的路径注册到 ROS 插件搜索路径中。

    • install(FILES ...)：指定安装的文件类型为普通文件。
    • DESTINATION：指定安装的目标路径。
    • ${CATKIN_PACKAGE_SHARE_DESTINATION}：这是 Catkin 提供的 CMake 变量，展开后为 share/<package_name>（例如 share/realsense2_camera）。
    • 作用：当执行 catkin_make install 或打包时，将 nodelet_plugins.xml 拷贝到系统的 ROS 工作空间共享目录下，使得其他 ROS 工具（如 pluginlib）能在全局范围内搜索到这个插件定义。
