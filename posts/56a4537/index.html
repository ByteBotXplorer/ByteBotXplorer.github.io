三点二次插值法

三点二次插值法（Three-point Quadratic Interpolation）是一种一维无约束优化算法。

插值逼近：对于复杂的一维单峰函数 f(x)，我们无法直接求出其极小值，但可以用一个简单的二次多项式（抛物线） 去 “贴合” 它的局部形态，再用抛物线的极小值近似代替原函数的极小值。

抛物线（二次函数）是最简单的具有 “单一极值” 的曲线，且其极值点可以通过解析式直接计算（无需迭代）。

算法步骤：

  1. 初始化

    初始化三点：$xL^1 = x{\min}, \quad xR^1 = x{\max}, \quad xM^1 = \frac{x{\min} + x_{\max}}{2}$，并计算出三点函数值。

  2. 拟合出二次函数 $g(x)$ 并求其极小值点

    通过三点 ((x_L^k, f_L))、((x_M^k, f_M))、((x_R^k, f_R)) 拟合二次函数 (g(x) = ax^2 + bx + c)，

    [ \begin{cases} ax_L^2 + bx_L + c = f(x_L) \ ax_M^2 + bx_M + c = f(x_M) \ ax_R^2 + bx_R + c = f(x_R) \end{cases} ]
    [
    \begin{bmatrix}
    f(x_L) \
    f(x_M) \
    f(x_R)
    \end{bmatrix}
    =
    \begin{bmatrix}
    x_L^2 & x_L & 1 \
    x_M^2 & x_M & 1 \
    x_R^2 & x_R & 1
    \end{bmatrix}
    \begin{bmatrix}
    a \
    b \
    c
    \end{bmatrix}
    ]
    求解系数 (a、b) 后，计算抛物线极小值点：

    [ x_{ms}^k = -\frac{b}{2a} ]

  3. 更新插值区间

    计算 (f(x_{MS}^k))，根据位置和函数值更新三点：

    | 条件 | 区间更新规则 |
    | ——————————————————————— | —————————————————————————————— |
    | (x{ms}^k < x_m^k) and (f(x{ms}^k) < fm) | (x_R^{k+1} = x_m^k, x_m^{k+1} = x{ms}^k, xL^{k+1} = x_L^k) |
    | (x    {ms}^k < xM^k) and (f(x{ms}^k) > fm) | (x_L^{k+1} = x{ms}^k, xm^{k+1} = x_m^k, x_R^{k+1} = x_R^k) |
    | (x    {ms}^k > xM^k) And (f(x{ms}^k) < fm) | (x_L^{k+1} = x_m^k, x_m^{k+1} = x{ms}^k, xR^{k+1} = x_R^k) |
    | (x    {ms}^k > xM^k) and (f(x{ms}^k) > fM) | (x_R^{k+1} = x{ms}^k, x_m^{k+1} = x_m^k, x_L^{k+1} = x_L^k) |

  1. 收敛判断

    如果 $|x_{ms} - x_m| < \epsilon$，退出；否则重复2-4迭代。
