正交视图和透视视图

正交视图（Orthographic View）

也叫正投影 / 平行投影，是将三维空间的点通过平行的投影线投射到二维平面上得到的视图。

核心特点

  1. 无透视变形：物体的实际尺寸、比例、角度在视图中完全保持不变，近大远小的视觉效果完全消失；
  2. 平行投影线：所有投影线相互平行，不交汇于某一点；
  3. 深度信息弱：视图中无法通过视觉直观判断物体的前后距离，需依靠标注、图层或多视图配合（如工程制图的三视图）。

适用场景

  • 工程制图（机械、建筑三视图：主视、俯视、左视）、CAD 绘图：保证尺寸和比例绝对准确，便于加工 / 施工；
  • 三维建模的精准编辑：如 Blender、3ds Max、SolidWorks 中的顶 / 前 / 侧视图，方便对齐、缩放、建模细节调整；
  • 2D 游戏 / UI：部分像素游戏、策略游戏（如《星际争霸》）的俯视视角，保持画面元素比例统一。

简单例子

看正方体的正交正视图，永远是一个标准的正方形，无论正方体离 “投影面” 多近多远，大小、形状都不会变。

透视视图（Perspective View）

也叫中心投影，是模拟人眼、相机的自然视觉规律，将三维空间的点通过交汇于一点（灭点 / 消失点）的投影线投射到二维平面上的视图。

核心特点

  1. 有近大远小：物体离观察点越近，在视图中显示越大；越远则越小，符合人眼的直观感受；
  2. 投影线交汇：所有投影线都从观察点出发，最终交汇于视平面后的灭点（单点透视 1 个灭点，两点透视 2 个灭点，三点透视 3 个灭点）；
  3. 深度信息强：无需额外标注，视觉上能直接感知物体的前后层次、空间距离和立体感；
  4. 存在视野边界：超出相机 / 人眼视野的部分会被裁剪，远处的平行线会向灭点汇聚（如公路向远方汇聚成一点）。

适用场景

  • 三维可视化、游戏渲染（如 3A 游戏、原神）、影视动画：还原真实的视觉效果，增强沉浸感；
  • 建筑效果图、室内设计：直观展示空间的透视关系和实际视觉感受；
  • 相机拍摄的真实画面、人眼看到的自然场景：本质都是透视视图。

简单例子

看正方体的透视正视图，会是一个梯形（或不规则四边形），离观察点近的面更大，远的面更小；远处的棱边会向灭点汇聚。
