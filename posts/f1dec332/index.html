传感器

一、所有传感器都是“波”吗？

只有主动发射/接收波来探测环境的传感器才是“波传感器”；
还有一大类是测自身运动/状态，不靠波。

1. 靠「波」工作的感知传感器（对外测环境）

  • 超声波雷达：机械波（声波）
  • 毫米波雷达：电磁波
  • 激光雷达：红外光波（电磁波）
  • 视觉相机：可见光波（电磁波）
  • 红外/热成像：红外电磁波

2. 不靠「波」的传感器（测自身状态）

  • IMU（陀螺仪+加速度计）：惯性力学、科氏力，不发波
  • GPS：接收卫星信号（算电磁波，但不是探测环境波）
  • 轮速计：电磁感应
  • 力控传感器：压电效应
  • 编码器：光电/磁电

二、按「波段轴」排列：波类传感器 + 实际优缺点

按波长从长到短排，越往右波长越短、精度越高，但越怕遮挡。

波长从长 → 短

超声波 → 毫米波雷达 → 热红外 → 激光雷达 → 可见光相机

1. 超声波雷达（机械声波，波长~cm级）

用途：小车避障、扫地机器人、近距离防撞

  • 优点
    • 极便宜，几十块
    • 不怕灰尘、烟雾、颜色
    • 对水、玻璃也能测
  • 缺点
    • 精度极差（cm级）
    • 速度慢，频率低
    • 易被风、噪音干扰
    • 无法建图、无法SLAM

2. 毫米波雷达（电磁波，波长~mm级）

频段：77GHz/79GHz（车载）
用途：自动驾驶测距、跟车、雨天行驶

  • 优点
    • 全天候：雨、雾、雪、沙尘完全不怕
    • 测速极准（多普勒效应）
    • 测距远（200m+）
    • 不受光照影响
  • 缺点
    • 点云非常稀疏，几乎没法建图
    • 没有角点/纹理信息
    • 无法识别物体类别
    • 静态目标容易滤掉

3. 激光雷达（红外光波，905nm/1550nm）

你用的 Mid-360 就是这类
用途：机器人建图、LIO-SLAM、三维感知

  • 优点
    • 三维精度极高（mm~cm级）
    • 点云稠密，能重建环境结构
    • 不受光照变化影响
    • 配合IMU做LIO最稳
  • 缺点
    • 大雨、浓雾、浓烟会衰减
    • 价格比毫米波/相机贵
    • 透明玻璃/镜面容易漏测

4. 可见光相机（光波 380~780nm）

用途：视觉SLAM、识别、分类、语义感知

  • 优点
    • 纹理、颜色、语义信息最强
    • 成本极低
    • 能识别人、车、牌子等一切物体
  • 缺点
    • 怕黑、怕强光、怕逆光
    • 无纹理区域（白墙、天空）失效
    • 纯视觉容易漂移，不如激光稳

三、怎么选

传感器 波类型 精度 抗雨雾 建图/SLAM 成本
超声波 机械声波 极差 强 不行 极低
毫米波雷达 电磁波 中 最强 弱 中
激光雷达 红外光波 极高 一般 最强 中高
视觉相机 可见光波 高 弱 较好 极低

按工作原理分类

  1. 惯性类（不靠波，纯力学原理）

    • 加速度计
    • 陀螺仪（MEMS，科氏力）
    • IMU

  2. 电磁波 / 光波类（靠电磁辐射）

    只有主动发射/接收波来探测环境的传感器才是“波传感器”

    • 激光雷达（红外光波）
    • 视觉相机（可见光）
    • 毫米波雷达（微波）
    • GPS（卫星电磁波）
    • 热成像（红外辐射）

  3. 机械波类（靠声波）
    超声波雷达

  4. 光电 / 电磁感应类

    • 编码器
    • 霍尔传感器
