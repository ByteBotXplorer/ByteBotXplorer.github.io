C++中字符类型

Created2026-02-01|Updated2026-02-05|编程C++
|Word Count:419|Reading Time:1mins|Post Views:

char

最基础的字符类型，通常占 1 字节（8 位）。

编码：默认使用系统本地编码（如 ASCII、GBK、UTF-8）。

用途：

  • 存储 ASCII 字符（0-127）。
  • 在 UTF-8 编码中存储多字节字符的单个字节。

  • 也常用于处理原始字节数据。

  • 特点：

    • 是 C++ 中唯一可用于字符串字面量（如 "hello"）的类型。
    • 可作为有符号或无符号类型，具体取决于编译器。

wchar_t

  • 宽字符类型，大小由实现决定，通常在 Windows 上为 2 字节（UTF-16），在 Linux/macOS 上为 4 字节（UTF-32）。

  • 编码：依赖平台，不统一。

  • 用途：

    • 处理超出 ASCII 范围的字符（如中文、日文）。
    • 在 Windows 系统中，配合 wstring 和宽字符 API 使用。

  • 特点：

    • 跨平台兼容性差，同一代码在不同系统上可能表现不同。
    • 字面量以 L 开头，如 L"你好"。

char16_t

C++11 引入的固定大小字符类型，占 2 字节（16 位）。

编码：专门用于 UTF-16 编码。

用途：

  • 存储 UTF-16 编码的字符（如大部分常用 Unicode 字符）。
  • 适合处理需要明确 2 字节宽度的场景。

特点：

  • 字面量以 u 开头，如 u"你好"。
  • 跨平台大小固定，比 wchar_t 更可靠。

char32_t

C++11 引入的固定大小字符类型，占 4 字节（32 位）。

编码：专门用于 UTF-32 编码。

用途：

  • 存储任意 Unicode 字符（包括辅助平面字符），一个字符占用一个 char32_t。
  • 适合需要直接访问 Unicode 码点的场景。

特点：

  • 字面量以 U 开头，如 U"你好"。
  • 跨平台大小固定，无需处理代理对。
