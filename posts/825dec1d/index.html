什么是HTTP重定向

HTTP 重定向是服务器告诉客户端 “你要访问的资源不在这个地址了，去新地址找” 的一种 HTTP 协议行为。

你去小区 A 栋 101 找快递，门口贴了纸条 “快递已搬到 B 栋 202”—— 这个 “纸条” 就是服务器返回的重定向响应，你的请求（找快递）需要按指引去新地址。

在网络请求中，客户端（wget/curl/ 浏览器）发送请求后，服务器不返回目标资源（比如 deb 安装包），而是返回一个 “新地址” 和重定向状态码，客户端会根据规则决定是否跳转到新地址。

重定向的核心类型

重定向的核心是状态码，不同状态码代表不同的重定向规则。

状态码 名称 含义（通俗版） 常见场景
301 Moved Permanently 资源永久搬家了（旧地址作废） 网站域名更换、旧链接下线
302 Moved Temporarily 资源临时搬家（可能还会回来） 防盗链、临时维护、版本更新

遇到情形：

最终 wget 跟着重定向走到了官网首页，下载了 HTML 网页（156KB），而非目标 deb 包（约 72MB）。

其他概念

重定向不是wget工具的特性，而是HTTP协议层面的通用行为。

任何基于 HTTP 的客户端都会遇到重定向：

  • 浏览器：访问旧网址自动跳新网址（比如微博旧域名跳新域名）；
  • curl：默认不跟随重定向，需加-L参数才会跳；
  • wget：默认自动跟随重定向（这也是你没手动操作，却自动跳转到官网的原因）；
  • 编程语言请求（Python requests）：默认跟随重定向，可通过参数关闭。
