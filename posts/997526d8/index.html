QNX

QNX Neutrino RTOS

是一种商业化的实时操作系统 RTOS（Real-Time Operating System），主要用于车载、工业控制、医疗设备、机器人、航空航天等高可靠嵌入式场景。它现在属于 BlackBerry QNX 体系，官方定位是面向嵌入式和自治系统的安全实时操作系统、Hypervisor 和开发工具平台。

实时指响应时间可预测。强调：

  • 任务什么时候被调度
  • 中断什么时候响应
  • 消息什么时候处理
  • 系统最坏情况延迟是多少

微内核架构

QNX 是 微内核 Microkernel 操作系统，QNX 微内核实现核心 POSIX 特性以及 QNX OS 的基础消息传递服务，文件和设备 I/O 等不子啊微内核里的功能由可选进程和共享库提供。

Linux

很多系统功能运行在内核态：

  • 进程调度
  • 内存管理
  • 文件系统
  • 网络协议栈
  • 设备驱动

如果某些内核模块或驱动严重出错，可能导致整个系统崩溃。

QNX

QNX 内核只保留最核心功能：

  • 线程调度
  • 进程间通信 IPC
  • 中断处理
  • 定时器
  • 部分基础内存管理

很多功能放到用户态进程中：

  • 文件系统
  • 网络协议栈
  • 设备驱动
  • 资源管理器
  • 应用服务

QNX OS 架构由微内核和多个协作进程组成，进程之间通过 IPC 通信，其中 message passing 是主要 IPC 形式。

实时调度清晰

QNX 面向实时系统，任务优先级、调度、中断响应设计得更适合确定性控制。

机器狗控制中：

实时系统要求：高优先级控制任务不能被低优先级日志任务长时间阻塞。

模块化强

需要什么服务，就启动什么服务。不需要的驱动、文件系统、网络服务可以不加载。
