Q-learning

  • Model-free Reinforcement Learning
  • Off-policy Temporal Difference Learning
  • Value-based Method

Q-learning 的目标是学习一个 Q-table，让智能体知道：在某个状态下，执行哪个动作的长期收益最大。

Q-learning 通过不断与环境交互，使用 Bellman target 和 TD error 更新 Q-table，最终学习出在每个状态下应该选择哪个动作的最优策略。

Q-value

$Q(s,a)$ 在状态 s 下执行动作 a，之后按照某种策略行动，最终能获得的长期期望回报，不是当前收益。

Q-table

Q值表是一个简单查找表，存储所有状态-动作对的 Q-value。

  • Q-table 的每一行是一个状态
  • 每一列是一个动作
  • 表格里的值是 Q-value

Q-function

在当前状态 $s_t$ 下执行动作 $ a_t$，之后按照策略 $\pi$ 继续行动，未来能得到的折扣累计奖励的期望值。

Bellman 最优方程

当前动作的最优价值 = 当前奖励 + 折扣后的下一状态最优动作价值

算法流程

Initialize $Q(s, a)$ arbitrarily
Repeat for each episode:
Initialize $s$:

​ Repeat for each step of episode:

​ Choose $a$ from $s$ using policy derived from $Q$

​ Take action $a$, observe $ r, s’$

​ $Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a’} Q(s’, a’) - Q(s, a)]$

​ $s \leftarrow s’$

​ until $s$ is terminal

Q-learning 更新

  • $Q(s, a)$: 当前 Q-table 中已有的估计值
  • bellman target = $r+\gamma \max_{a’}Q(s’,a’)$: 这次经验给出的目标值
  • Temporal Difference error = $r+\gamma \max_{a’}Q(s’,a’)-Q(s,a)$
  • $\alpha \in (0, 1]$: 学习率，控制 Q-value 每次更新多少
  • $\gamma$: 折扣因子，控制未来奖励的重要性。越接近1，越看重长期收益

epsilon-greedy 策略

以 $\epsilon$ 概率随机探索，以 $1-\epsilon$ 概率选择当前最优动作。
