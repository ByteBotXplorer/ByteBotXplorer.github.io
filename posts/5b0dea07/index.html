Deep Q Network

在普通的Q-learning中，当状态和动作空间是离散且维数不高时可使用Q-Table储存每个状态动作对的Q值，而当状态和动作空间是高维连续时，使用Q-Table不现实，我们无法构建可以存储超大状态空间的Q-table( $ Q(s, a) $ )。

DQN 使用神经网络近似 Q- function—— $Q(s, a; \theta) $；网络输入状态 $s$，一次输出所有离散动作的 Q 值—— $Q(s, \cdot ; \theta) = [Q(s, a_1), Q(s, a_2), \cdots, Q(s, a_n)] $；执行动作通常为 $a = \arg\max_a Q(s,a;\theta)$。

experience replay

每个时间步（time-step）将一条转移 $et = (s_t, a_t, r_t; s{t+1})$ 存起来，这些转移累积成一个 replay memory——$D_t = {e_1, \cdots, e_t }$。模型训练时不是直接使用最新一步，而是从记忆池里随机采样，然后对这些样本做 Q-learning 更新。

DQN 目标策略与动作策略分离，学习时利用经验池储存的经验取 batch 更新 Q。

原因：

  • 连续帧高度相关，直接学习不稳定；
  • 随机采样可以降低更新方差；

  • 不稳定：

    1. Q值震荡
    2. 策略频繁改变：动作变化，采样的数据分布变化，后续更新方向变化
    3. 发散：优化过程不收敛、价值估计失真、参数更新失控

  • 更新方差：每次参数更新的方向和大小，非常依赖样本；不同样本导致的梯度差异很大。

算法流程

Initialize replay memory $D$ to capacity $N$

Initialize action-value function $Q$ with random weights $\theta$ —— $Q(s, a; \theta) $，在线网络

Initialize target action-value function $\hat{Q}$ with weights $\theta^- = \theta$，目标网络

For episode = 1, $M$ do

​ Initialize sequence $s_1 = {x_1} $ and preprocessed sequence $\phi_1 = \phi(s_1)$

​ For $t$ = 1, $T$ do

​ With probability $\epsilon$ select a random action $a_t$

​ otherwize select $a_t = \arg\max_a Q(\phi(s_t), a; \theta)$

​ Execute action $at$ in emulator and observe reward $r_t$ and image $x{t+1}$

​ Set $s{t+1} = s_t, a_t, x{t+1} $ and preprocess $\phi{t+1} = \phi(s{t+1})$

​ Store transition $(\phit, a_t, r_t, \phi{t+1})$ in $D$ (存入经验回放池)

​ Sample random minibatch of transitions $(\phij, a_j, r_j, \phi{j+1})$ from $D$

​ Perform a gradient descent step on $(yj - Q(\phi{j+1}, a’; \theta^-))^2$ with respect to the network parameters $\theta$ (计算损失并更新在线网络)

​ $L(\theta) = \frac{1}{B} \sum_{j=1}^{B} \left[ y_j-Q(\phi_j,a_j;\theta) \right]^2$

​ 梯度下降更新在线网络参数 $\theta$：$\theta \leftarrow \theta-\alpha\nabla_\theta L(\theta)$

​ Every $C$ steps reset $\hat{Q} = Q$

​ End For

End For

  • $D$: 存放与环境的历史交换经验值 $(\phit, a_t, r_t, \phi{t+1})$，回放池中保存的不是最优解，而是实际经验
  • $Q$: on-line network，根据状态选择动作，计算当前 Q 值，提督下降更新。训练目标值 $yt = r_t+\gamma\max{a’}Q{\text{target}}(\phi{t+1},a’;\theta^-)$，在状态 $\phit$ 执行动作 $a_t$，得到实际奖励 $r_t$，到达实际状态 $\phi{t+1}$，然后从下一状态开始选择当前估计的最优动作。学习目标 $Q^(\phit,a_t) = \mathbb{E} \left[ r_t+\gamma\max{a’}Q^(\phi_{t+1},a’) \right]$
  • $\hat{Q}$: 目标网络，只计算训练目标，在一段时间内保持不变
  • $\phi$: 图像预处理操作
  • $s_t$: 从开始到当前时刻的交互历史序列
  • $\phit$: $\phi{t+1}(s_t)$，从历史序列中提取出的固定大小网络输入，从历史序列中取最近若干帧
  • $y_j$: 目标网络构造的目标值
