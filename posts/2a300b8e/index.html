Shell原理与命令行

Created2026-05-16|Updated2026-07-10|Linux
|Word Count:770|Reading Time:2mins|Post Views:

Shell 是什么？

Shell 是用户与操作系统内核之间的命令解释器。

Shell 职责：

  • 接收用户输入
  • 解析命令
  • 查找可执行程序
  • 设置环境变量
  • 处理管道、重定向、通配符
  • 调用操作系统接口启动程序

终端 Terminal

内置命令
