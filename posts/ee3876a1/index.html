驱动

驱动主要分为：

  • 内核态
  • 用户态
  • 固件 firmware
  • 库文件和运行时

用户态和内核态

“态”是 CPU 当前运行代码的权限等级

用户态 User Space

平时运行的大部分程序都在用户态：

  • Python 程序
  • C++ ROS 节点
  • rviz
  • roscore
  • 浏览器
  • 终端
  • SLAM 算法
  • 导航程序
  • 深度学习推理程序

用户态程序权限较低，不能直接访问硬件，不能随便操作内存，不能直接控制中断。

内核态 Kernel Space

内核态是操作系统内核运行的地方。

Linux 内核运行在高权限模式。

固件 firmware

固件不是普通 Linux 程序，也不是普通内核模块，是给硬件内部小处理器运行的代码。

例如：

  • WiFi 固件
  • 蓝牙固件
  • GPU 固件
  • 摄像头 ISP 固件
  • 编码器/解码器固件
