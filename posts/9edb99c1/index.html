nmcli

nmcli = NetworkManager Command Line Interface 是「网络管理器」的命令行接口。是 Linux（Ubuntu 18.04+、Jetson）默认的网络管理工具，替代了老旧的ifconfig/iwconfig，核心是「统一管理所有网络设备」（WiFi、以太网、蓝牙、热点）。

  • NetworkManager：是 Linux（Ubuntu/Jetson）的核心网络管理服务，负责统一管理 WiFi、以太网、蓝牙等网络设备，替代了传统的ifconfig/iwconfig等零散工具；

  • nmcli：是操作 NetworkManager 的命令行工具，配置 WiFi / 热点的所有操作，本质都是通过 nmcli 告诉 NetworkManager 去执行。

核心概念

概念 含义 例子
Device（设备） 物理网络硬件（网卡），是 “硬件层面” wlP1p1s0（WiFi 网卡）、enP8p1s0（以太网）
Connection（连接） 网络配置文件（逻辑层面），一个 Device 可以绑定多个 Connection 你的手机热点连接、Jetson 的 Hotspot 连接
