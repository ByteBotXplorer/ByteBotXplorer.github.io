最优化基础——一维搜索

Created2026-01-29|Updated2026-02-12|最优化
|Word Count:2.2k|Reading Time:8mins|Post Views:

定义

对于目标函数 $f : \mathbb{R} \rightarrow \mathbb{R}$ 的单值函数的最小化问题的迭代求解的方法。

暴力搜索法

暴力搜索法（枚举搜索法/网格搜索法）：在搜索区间内按固定步长遍历所有候选点，筛选出目标函数的最优值点，逻辑简单但精度由步长决定，步长越小精度越高、计算量越大。

  • 适用场景：一维单峰/多峰函数的粗略最优值搜索，作为后续高精度搜索的初值选择
  • 计算量：$k = ceil(\frac{x{max}-x{min}}{step}) + 1$
  • 精度控制：极小值近似精度 ≤ step，步长 step 越小精度越高，计算量成反比增加
  • 边界处理：循环条件 x ≤ b 确保遍历到搜索区间右端点，无遗漏
  • 局限性：仅适用于一维搜索，高维场景计算量会指数级爆炸，无实用价值

区间消去法

如果 $f(x)$ 定义在 $[x{min}, x{max}]$ 上，在 $x0 \in [x{min}, x{max}]$ 左边递减，右边递增，那么 $f(x)$ 就是在 $[x{min}, x{max}]$ 上的单谷函数，$f(x_0)$ 就是 $f(x)$在 $[x{min}, x_{max}]$ 上的最小值（谷值），$x_0$是谷值点。

区间消去法是单峰函数的一维搜索方法。利用单峰性，通过比较区间内两点的函数值，消去不可能包含极小值的区间，逐步缩小区间范围，最终以区间中点作为近似极小值点。

  • 迭代稳定：固定分割比例 $r=0.25$，每次消去固定比例无效区间，收敛过程平稳，无震荡；

  • 计算量：

    $ k = [ceil(\frac{log(\epsilon / (x{max} - x{min}))}{log(1-r)}) + 1]* 2$

  • 硬约束：分割比例必须小于0.5

  • 收敛速度：$r $越接近 0.5，每次消去的无效区间比例越大，剩余有效区间越小，迭代次数越少，收敛越快。

  • 分割比例随精度要求动态调整，在「每次消去尽可能多的无效区间」和「两个分割点不重合、保留有效判断空间」之间取最优平衡，最终实现迭代次数最少、收敛速度最快：$r=0.5−0.1ε$

黄金分割法

黄金分割法（Golden Section Search）是区间消去法的高效优化版本，核心是通过黄金分割比例 $1 - \rho =\frac{\sqrt{5}−1}{2} \approx 0.618 $ 来复用前一次迭代的计算结果，从而将每次迭代的函数值计算次数从 2 次减少到 1 次。

  • 函数计算量：$ k = [ceil(\frac{log(\epsilon / (x{max} - x{min}))}{log(1-\rho)}) + 1]$
  • 除首次迭代需计算 2 个内点的函数值外，后续每轮迭代仅需计算 1 个新内点 的函数值（复用前一次的内点）

斐波那契法

斐波那契法是有限步内最优的一维单峰函数区间消去法，核心是用斐波那契数列确定每一步的分割比例，在给定迭代步数下，使区间压缩比达到最小，同时实现计算复用，每次迭代仅需一次函数值计算。

不再与黄金分割法需要每次分割的 $\rho$ 数值相同，而是前后两次的分割比例有一定的关系，$\rho_{k+1} = 1 - \frac{\rho_k}{1 - \rho_k}$，则区间总体压缩比例：$(1-\rho_1)(1-\rho_2)\cdots(1-\rho_N)$。

最优化问题变成：

斐波那契数列：

$F0 = 0, F_1 = 1, F_k = F{k-1} + F_{k-2}$

最优解：

实际代码中 $\rho_N = \frac{1}{2} - 0.1 \epsilon$

区间长度压缩比 $\frac{LN}{x{max}-x{min}} = \frac{1}{F{N+1}}$

求解得到最大迭代次数 $N$

  • $\frac{x{max}-x{min}}{F_{N+1}} \leq \epsilon$ 求解出迭代次数，每次迭代只调用1次函数

  • 斐波那契法所需的迭代次数是满足精度的最小次数

  • 可以将斐波那契数列的比值预计算后存储在硬件中（查表法），这是嵌入式 / 实时系统中优化斐波那契法的核心手段 —— 既能规避迭代中计算斐波那契数列和除法的耗时，又能保证算法精度

总结

暴力搜索 / 区间消去 / 黄金分割 / 斐波那契法：

  • 只看函数值，通过比较区间内不同点的函数值大小，来消去不可能包含极小值的区间，逐步收敛。
  • 只要求函数在区间内是单峰的，不要求可导，甚至不要求连续。
  • 收敛速度通常是线性的（区间长度按固定比例缩小）。
