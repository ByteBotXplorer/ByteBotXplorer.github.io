PCD文件是什么

PCD（Point Cloud Data，点云数据文件），是PCL（Point Cloud Library）定义的标准3D数据格式。

The Point Cloud Library (PCL) is an open-source, cross-platform C++ framework for 2D and 3D point-cloud and image processing. It provides a comprehensive suite of algorithms for filtering, registration, segmentation, feature extraction, surface reconstruction, and visualization of spatial data. PCL is widely used in robotics, computer vision, and mapping for building 3D perception systems.

存储内容：记录的是3D 空间点的信息，每个点包含：

  • 坐标：x,y,z（空间位置）
  • 可选：颜色 r,g,b、法向量、强度等

用于：

  • 存储点云（3D坐标 + 属性）

  • 用于SLAM、建图、配准（ICP / NDT / GICP）

  • 常见于激光雷达、RGB-D 相机数据

PCD文件结构

PCD文件 = Header（头部）+ Data（数据）

  • VERSION 0.7：PCD格式版本

  • FIELDS x y x intensity：定义了每个点包含哪些数据：

    字段顺序 = 数据存储顺序

    | 字段 | 含义 | 来源 |
    | ————————————— | ———— | ——————————————————— |
    | x y z | 三维坐标 | |
    | intensity | 激光强度 | 激光雷达（Velodyne/Livox），不需要计算 |
    | rgb | 颜色 | |
    | normal_x normal_y normal_z | 法向量 | 局部平面拟合（PCA） |
    | curvature | 曲率 | λ_min / (λ1 + λ2 + λ3) |

  • SIZE：每个字段占据多少字节

    | 类型 | 字节 |
    | ——— | —— |
    | float | 4 |
    | double | 8 |
    | uint8 | 1 |

  • TYPE：数据类型

    | 标记 | 类型 |
    | —— | ———— |
    | F | float |
    | I | int |
    | U | unsigned |

  • COUNT：每个字段元素数

  • HEIGHT和WIDTH：点云结构

    1. 无序点云

    2. 有序点云（图像结构，比如深度相机）

  • VIEWPOINT tx ty tz qw qx qy qz：

    • 平移+四元数旋转
    • 定义点云采集时的相机位姿

  • POINTS：总点数 = WIDTH $\times$ HEIGHT

  • DATA：数据格式

    • ASCII可读性好

    • binary二进制

    • binary_compressed压缩
