world文件

Created2026-06-02|Updated2026-07-10|ROS
|Word Count:702|Reading Time:3mins|Post Views:

.world 是一个 Gazebo World 文件，本质上是一个 SDF（Simulation Description Format）格式的 XML 文件，用于描述仿真世界中的：

  • 地面
  • 光照
  • 机器人
  • 障碍物
  • 传感器
  • 物理引擎参数
文件 作用
world 描述整个世界
urdf 描述机器人
xacro 生成 URDF
rviz 描述可视化界面
launch 启动系统

SDF 文件整体结构

XML 声明

告诉解析器：这是 XML 文件，使用 XML1.0 标准

类似C++：#include <iostream>

sdf 标签

SDF：Simulation Description Format

按照 SDF 1.6 规范解析

world 标签

定义一个仿真世界。

相当于：

include 语法

加载 Gazebo 自带太阳

加载 Gazebo 地面

model 标签

开始定义一个模型

static 标签

固定物体，不会受重力、碰撞影响而移动

pose 标签

单位：

位置：mi；角度：弧度

相对世界原点的位置

link 标签

表示刚体

collision 标签

用于碰撞检测、物理计算

geometry 标签

定义几何形状

visual 标签

用于物理显示和渲染，不参与碰撞。

material 材质

ambient 环境光

diffuse 漫反射

表示：光源找到物体后反射出来的颜色
